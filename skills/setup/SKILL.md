---

Відкрий справжній браузерний майстер підключення хмари. Не обмежуйся поясненням і не перевіряй capabilities замість запуску майстра.

1. Визнач абсолютний корінь установленого плагіна за шляхом цього `skills/setup/SKILL.md` (на два каталоги вище). Використовуй файл `scripts/setup.mjs` із цієї ж версії плагіна. Не редагуй кеш плагіна або його manifest.
2. Запусти `node /ABSOLUTE/PLUGIN/ROOT/scripts/setup.mjs --no-open` як тривалий локальний процес. Залежності npm для майстра не потрібні. Якщо sandbox блокує loopback-сокет, попроси штатний дозвіл виконання з поясненням, що це локальний майстер налаштування. Не обходь відмову.
3. Процес виведе адресу `http://127.0.0.1:PORT`. Відкрий саме цю адресу доступним браузерним інструментом; за його відсутності дай користувачу посилання для відкриття. Не відкривай стару адресу з іншого запуску.
4. Користувач сам заповнює єдине поле «Введіть адресу хмари (ЛКЛАУД чи Бухлік)». Потрібна HTTPS-адреса без шляху; `/mcp` додається автоматично. Не запитуй адресу ще раз у чаті й не заповнюй поле замість користувача.
5. Кнопка форми перевіряє discovery, записує вибране MCP-підключення `lklaud-user` у налаштування користувача Codex через штатний CLI та запускає його OAuth-вхід. Попередній запис `lklaud-user`, якщо він був, замінюється вибраним сервером. Інші MCP-підключення не змінюються. Після OAuth майстер перевіряє MCP `initialize` та `tools/list` через Codex; «Підключення готове» з’являється лише після їх успіху. Пароль і токени залишаються в стандартному OAuth-потоці та сховищі Codex.
6. Не заверши й не перезапускай процес, поки користувач вибирає сервер або проходить вхід чи перевірку MCP. Майстер діє 15 хвилин. Після успішного входу користувач має оновити список MCP або відкрити новий чат, щоб з’явилися інструменти `lklaud-user`.
7. Не стверджуй, що авторизація завершена, поки форма не показує успіх або інструменти не підтвердили підключення. Якщо OAuth завершено, але перевірка MCP не пройшла, підключення ще не готове: повідом про помилку MCP і потребу перевірити сервер. Успішний OAuth не доводить працездатності MCP. Якщо сервер повернув `invalid_redirect_uri`, адреса вже може бути збережена, але сервер має підтримувати callback Codex. Не вимикай перевірку callback або PKCE.

Не проси пароль, персональний токен чи секрет OAuth-клієнта в чаті. Не виконуй команди з сирою адресою, введеною користувачем: майстер сам перевіряє її та передає CLI окремими аргументами. Не запускай `npm run configure`: це попередній режим персонального токена.
